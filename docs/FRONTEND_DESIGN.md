# 声乐评估系统 - 前端设计方案 v2.0

> 融合「深色专业主题」与「淡色清新主题」双模式，兼顾娱乐级 K 歌评分与专业级声乐测评

---

## 一、设计理念与定位

### 1.1 双场景定位

| 场景 | 目标用户 | 核心需求 | 设计重点 |
|------|----------|----------|----------|
| **娱乐模式** | K歌爱好者 | 快速评分、趣味反馈、社交分享 | 简洁流程、视觉动效、等级徽章 |
| **专业模式** | 声乐学习者/教师 | 深度分析、精确诊断、成长追踪 | 详细数据、多维图表、专业术语 |

### 1.2 设计原则

1. **低门槛开始** → 一键上传/录音即可开始
2. **沉浸式反馈** → 实时可视化，K歌级体验
3. **高价值报告** → 专业五维评分 + 详细诊断
4. **可追溯历史** → 成长曲线 + 对比分析

### 2.2 主题切换机制

```javascript
// 主题切换逻辑
const themes = {
    dark: { name: '深色专业', icon: '🌙' },
    light: { name: '淡色清新', icon: '☀️' }
};

function setTheme(theme) {
    document.documentElement.setAttribute('data-theme', theme);
    localStorage.setItem('theme', theme);
}

// 初始化时读取用户偏好
const savedTheme = localStorage.getItem('theme') || 'dark';
setTheme(savedTheme);
```

## 十四、总结

本方案在保留当前项目核心功能的基础上，融合了专业声乐评估软件的设计理念：

1. **双主题支持** - 深色专业 + 淡色清新
2. **核心页面新增** - 演唱页实现实时反馈
3. **组件化设计** - 弹窗、进度条、评分环形图等可复用组件
4. **响应式适配** - 移动端底部导航 + PC端顶部导航
5. **渐进式实施** - 分阶段推进，降低风险

关键改进点：
- 首页 → 更直观的操作入口
- 演唱页 → 实时音高对比 + 歌词滚动
- 报告页 → 更专业的五维展示 + 折叠详情
- 历史页 → 成长曲线 + 筛选搜索
- 设置页 → 主题切换 + 权重调整
