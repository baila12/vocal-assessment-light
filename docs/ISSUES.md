### 逐句评分优化详情 (v5.9 - 2026-05-10)

**问题根因**：
- 音准评分把"音高变化幅度"误判为"音准差"
- 演唱中的转音、滑音会导致高 relative_std（30%-50%），这是正常的音乐表达
- 最低分过低（30-40分）

**最终修复方案**：
```python
# services/phrase_service.py
# 音准阈值大幅放宽
PITCH_THRESHOLD_EXCELLENT = 0.12   # 12%
PITCH_THRESHOLD_GOOD = 0.30        # 30%
PITCH_THRESHOLD_FAIR = 0.50        # 50%
PITCH_MIN_SCORE = 60.0             # 最低分 60

# 节奏评分优化
RHYTHM_STABLE_MIN = 75.0           # 稳定节奏最低 75 分

# 气息评分优化
BREATH_THRESHOLD_EXCELLENT = 0.10  # 10%
BREATH_MIN_SCORE = 60.0            # 最低分 60

# 情绪评分重构
EMOTION_BASE_SCORE = 70.0          # 基准分 70
EMOTION_MIN_SCORE = 60.0           # 最低分 60

# 音量评分
VOLUME_MIN_SCORE = 60.0            # 最低分 60
```

**最终效果**：

| 音频 | 维度 | 原始 | 最终 | 改进 |
|------|------|------|------|------|
| 恋人 | 音准 | 66.1 | **79.9** | +13.8 |
| 恋人 | 情绪 | 69.2 | **73.9** | +4.7 |
| 恋人 | 总分 | 78.4 | **84.4** | +6.0 |
| 手写的从前 | 音准 | 56.2 | **74.0** | +17.8 |
| 手写的从前 | 情绪 | 61.9 | **73.1** | +11.2 |
| 手写的从前 | 总分 | 73.2 | **81.7** | +8.5 |
