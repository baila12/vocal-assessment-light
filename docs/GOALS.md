# 项目目标设计文档 v1.0

## 一、项目定位

### 1.1 核心定位
**离线声乐评估系统 (VAS)** - 纯本地化、无服务器、无需登录的专业声乐评估 Web 应用。

### 1.2 核心价值
- **隐私保护**: 全离线运行，所有数据本地存储，不上传云端
- **专业评估**: 五维评分算法 + 深度学习模型 (Wav2Vec2/CREPE/SingMOS/Demucs)
- **即开即用**: 一键启动 Flask 服务，浏览器自动打开
- **双模式评估**: 快速模式 (~33秒) / 专业模式 (~220秒)

### 1.3 技术栈
| 层级 | 技术 |
|------|------|
| 后端 | Flask 3.0 + librosa + scipy + numpy + matplotlib |
| 深度学习 | transformers + torchcrepe + speechbrain + demucs |
| 前端 | HTML5 + ES6 Modules + Chart.js + Web Audio API + Canvas |
| 存储 | IndexedDB (前端) + JSON (后端) |
| 测试 | pytest + Playwright |

## 五、页面跳转逻辑

### 5.1 全局跳转规则

| 规则 | 说明 |
|------|------|
| 无刷新路由 | 基于 HTML5 History API |
| 参数校验 | 无效参数跳转首页 |
| 导航栏全局可用 | 4 个核心页面一键跳转 |
| 返回按钮 | 遵循浏览器历史记录 |
| 服务异常 | 停留当前页，提示重启 |

### 5.2 详细跳转链路

| 源页面 | 目标页面 | 触发条件 | 参数 | 回退 |
|--------|----------|----------|------|------|
| 服务启动 | 首页 | 启动成功 | 无 | 无 |
| 首页 | 分析结果页 | 点击「开始分析」 | file_id | 返回首页 |
| 首页 | 对比分析页 | 点击「对比分析」 | 无 | 返回首页 |
| 首页 | 历史记录页 | 点击导航「历史」 | 无 | 返回首页 |
| 首页 | 设置页 | 点击导航「设置」 | 无 | 返回首页 |
| 分析结果页 | 对比分析页 | 点击「加入对比」 | file_id (B轨) | 返回分析页 |
| 历史记录页 | 分析结果页 | 点击记录卡片 | file_id, from=history | 返回历史页 |
| 历史记录页 | 对比分析页 | 勾选2条+「对比」 | file_a, file_b | 返回历史页 |
| 对比分析页 | 分析结果页 | 点击「查看详情」 | file_id, from=compare | 返回对比页 |
| 任意页 | 首页 | 404/参数无效 | 无 | 无 |

### 5.3 页面状态保持

| 页面 | 状态保持 |
|------|----------|
| 首页 | 已导入/录制的音频保留 |
| 分析结果页 | 通过 file_id 重新加载 |
| 对比分析页 | 已选音频、对比结果保留 |
| 历史记录页 | 筛选条件、搜索词保留 |
| 设置页 | 实时保存到本地 |
