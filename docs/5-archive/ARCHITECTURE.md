## 设计理念

参考全民K歌、唱吧等主流K歌应用的UI设计，结合VoiceLab等专业音频分析工具的功能深度，打造：
- **简洁不杂乱** - 核心功能突出，操作直观
- **实时反馈** - 类似K歌动效的实时视觉体验
- **专业深度** - 多维度分析，智能改进建议
- **离线优先** - 完全本地化，保护用户隐私

## 1. 页面结构

### 页面划分
| 页面 | 路由 | 功能 |
|------|------|------|
| 主页 | `home` | 录音/导入入口、实时分析显示 |
| 分析结果 | `result` | 完整分析报告、雷达图、改进建议 |
| 对比分析 | `compare` | 标准音频对比、差异高亮 |
| 历史记录 | `history` | 时间/分数筛选、成长曲线 |
| 设置 | `settings` | 音频参数、评分标准配置 |

### 页面切换逻辑
```
主页（默认）───录音/导入──→ 分析结果
    │                          │
    │                          ├── 保存到历史
    │                          └── 加入对比 → 对比分析
    │
    └── 历史记录 ──点击记录──→ 分析结果
```

## 6. 实时显示组件

### 6.1 动态波形可视化
- 实时滚动的波形
- 音量电平条（左右声道）
- 峰值预警（红色标记爆音）

### 6.2 实时数据面板
| 显示项 | 格式 | 说明 |
|--------|------|------|
| 当前音高 | C4 (262Hz) | 音名 + 频率 |
| 音高偏差 | ↑+5¢ / ↓-3¢ | 音分偏差，箭头指示方向 |
| 当前音量 | -12.3 dB | 分贝值 + 电平条 |
| 实时评分 | 85分 | 实时累计评分 |
| 当前情绪 | 开心😊 | 情绪标签 |

### 6.3 实时提示条
根据分析结果动态显示提示：
- "音偏高了 → 往下压一点"
- "气息不稳 → 放慢呼吸"
- "音色偏闷 → 打开口腔"
- "节奏偏快 → 稍稳一点"

## 7. 后端API设计

### 新增/修改API
```
POST /api/record/start     # 开始录音
POST /api/record/stop      # 停止录音，返回分析结果
GET  /api/realtime         # WebSocket实时分析数据流
POST /api/analyze          # 完整分析（含波形、音高、音色）
GET  /api/waveform         # 波形数据
GET  /api/pitch-curve      # 音高曲线数据
GET  /api/timbre           # 音色分析数据
GET  /api/standards        # 标准音频列表
POST /api/compare          # 对比分析
GET  /api/history          # 历史记录（支持时间/分数筛选）
GET  /api/history/growth   # 成长曲线数据
```
