# 深度学习模型集成方案

## 目标

在无音乐库、无版权限制的前提下，通过深度学习模型提高评估的准确度、效率和客观性。

## 核心原则

1. **无版权依赖** - 不使用任何歌曲模板或音乐库
2. **绝对音质评估** - 评估"唱得好不好"，而非"唱得像不像"
3. **端侧可运行** - 所有模型可在本地 CPU/GPU 运行
4. **降级备用** - 模型不可用时回退到传统算法

---

## 模型集成方案

### 1. 基频提取升级：YIN → CREPE-Tiny

**现状**: 使用 librosa.yin (传统信号处理)

**问题**:
- 强伴奏下准确率下降
- 低音区、气声段检测不稳定
- 对演唱技巧（颤音、滑音）处理不佳

**升级方案**: CREPE-Tiny (轻量化深度学习基频提取)

```
模型大小: ~5MB (INT8 量化)
推理速度: ~3ms/帧 (CPU)
准确率提升: 15-20% (强伴奏场景)
```

---

### 2. 人声质量检测：深度学习分类器

**用途**: 在分析前判断音频是否适合评估

**检测内容**:
- 是否包含人声
- 人声占比是否足够
- 是否为纯伴奏/纯音乐
- 是否为噪声/无效音频

**模型选型**: 轻量 CNN

```
模型大小: ~2MB
推理速度: ~10ms (整段音频)
准确率: >95%
```

---

### 3. 唱法识别：深度学习分类器

**用途**: 自动识别演唱风格，调整评分标准

**分类类别**: 流行/美声/民族/说唱/爵士

**模型选型**: ResNet-18 + 迁移学习

```
模型大小: ~10MB
推理速度: ~15ms
准确率: >90%
```

---

### 4. 音准评估：自参照 DTW 对齐

**核心思路**: 不需要歌曲模板，从演唱本身提取"自我参照标准"

**原理**:
1. 用户演唱中，每个音符的"稳定段"代表其"想要唱的音高"
2. 提取每个音符的核心稳定段作为"参考音高"
3. 计算过渡段、波动段与参考音高的偏差

**优势**:
- 无需歌曲模板
- 评估用户"唱得是否稳定"
- 区分"有意波动"vs"无意跑调"

---

### 5. 气息评估：深度学习 + 声学特征融合

**检测内容**:
- 气息断层检测
- 漏气检测
- 气声技巧识别
- 呼吸点检测

**模型选型**: BiLSTM + CRF (序列标注)

```
模型大小: ~3MB
推理速度: ~20ms
F1-score: >0.85
```

## 性能优化策略

### 1. 双评估模式

**快速评估模式** (默认):
- 跳过逐句评分 (最耗时的部分)
- 跳过音色分析
- 跳过可视化图表生成
- 仅提供基础五维评分
- 适用场景: 快速练习反馈

**专业评估模式**:
- 完整分析流程
- 逐句评分 (多线程并行)
- 音色分析
- 可视化图表
- 适用场景: 详细问题诊断

### 2. 多线程并行处理

**逐句评分优化**:
```python
# 使用 ThreadPoolExecutor 并行评分
with ThreadPoolExecutor(max_workers=4) as executor:
    futures = {executor.submit(score_phrase, ...): i for i in range(n)}
```

**效果**: 逐句评分速度提升 2-3 倍

### 3. 预计算数据复用

避免重复计算:
- f0 (基频) 数据在主分析中计算，逐句评分直接复用
- RMS 能量数据复用
- onset 检测结果复用

### 4. GPU 加速 (未来)

可选优化方向:
- CREPE 基频提取 GPU 加速
- Demucs 人声分离 GPU 加速
- 深度学习推理 GPU 加速

### 客观公正性

- 统一的声学标准，不因歌曲而异
- 自动识别唱法，调整评分标准
- 无音乐库依赖，无版权风险
