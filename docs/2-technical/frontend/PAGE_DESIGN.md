## 二、标准曲库页 (#/songs)

### 2.1 页面结构

- **顶部**: 标题「标准曲库」+ 搜索框 + 「导入音频」按钮
- **筛选栏**: 难度筛选 (全部/初级/中级/高级) + 风格筛选 (全部/流行/民谣/美声等)
- **歌曲列表**: 卡片网格 (可切换列表视图)
- **空状态**: 「曲库为空，点击导入第一首标准歌曲」

### 2.2 歌曲卡片

每张卡片包含：
- 歌曲名（主标题）
- 歌手名（副标题）
- 难度标记（初级🟢/中级🟡/高级🔴）
- 风格标签（流行/民谣等）
- 时长 (mm:ss)
- 操作按钮: 「选择此歌」 / 「详情」 / 「删除」

### 2.3 交互流程

| 操作 | 行为 |
|------|------|
| 搜索 | 实时过滤，高亮匹配关键词 |
| 点击卡片 | 展开详情（调性、音域、BPM、预览播放器） |
| 点击「选择此歌」 | 跳转 #/sing/{songId} 进入录音准备 |
| 点击「导入音频」 | 弹出导入表单 |
| 筛选切换 | 立即过滤，带过渡动画 |
| 删除歌曲 | 二次确认后删除 |

### 2.4 边界条件

| 场景 | 行为 |
|------|------|
| 曲库为空 | 显示空状态引导，显示「导入音频」大按钮 |
| 搜索结果为空 | 显示「未找到匹配歌曲」提示 |
| 400+ 首大曲库 | 分页加载（每页 20 首） |
| 导入同名歌曲 | 提示「已存在同名歌曲」，可覆盖 |
| 网络断开 | 显示离线提示，「标准曲库」不可用 |

## 三、标准音频导入表单

### 3.1 表单字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 音频文件 | file | 是 | mp3/wav/flac/ogg/m4a |
| 歌曲名 | text | 是 | 唯一标识 |
| 歌手 | text | 是 | |
| 难度 | select | 是 | 初级/中级/高级 |
| 风格 | select | 是 | 流行/民谣/美声/R&B/摇滚 |
| BPM | number | 否 | 自动检测或手动输入 |
| 调性 | text | 否 | 如 C Major |
| 图片封面 | file | 否 | 可选 |

### 3.2 交互流程

1. 用户点击「导入音频」
2. 弹出导入表单 Modal
3. 用户选择文件 + 填写元数据
4. 点击「开始导入」
5. 显示上传进度条
6. 完成后 Toast 提示「已成功导入 {歌名}」
7. 自动关闭弹窗，刷新曲库列表

### 3.3 边界条件

| 场景 | 行为 |
|------|------|
| 文件过大 (>50MB) | 提示「文件过大，建议压缩后导入」 |
| 未填必填项 | 表单校验失败，高亮未填字段 |
| 上传失败 | 显示错误信息，保留已填数据 |
| 上传中断 | 可重新上传，不重复添加 |
| 非音频文件 | 文件选择器限制 audio/* |

## 四、演唱页选歌流程 (#/sing 改造)

### 4.1 当前问题

SingPage 路由 #/sing 直接展示录音界面，没有选歌流程；#/sing/:songId 虽然有参数，但没有从曲库加载歌曲数据的逻辑。

### 4.2 路由设计

| 路由 | 行为 |
|------|------|
| #/sing | 先展示歌曲选择（内联在页面顶部），选中后展示录音界面 |
| #/sing/:songId | 直接进入该歌曲的录音准备（带歌曲信息） |

### 4.3 #/sing（无参数）交互流程

1. 页面分为上下两区：
   - 上半区：歌曲选择区域（类似曲库的迷你列表）
   - 下半区：录音面板（灰色禁用状态）
2. 用户浏览/搜索曲库
3. 点击歌曲卡片
4. 选中歌曲高亮，录音面板解除禁用
5. 显示选中的歌曲信息（歌名 + 歌手 + BPM + 调性）
6. 用户点击「开始录音」
7. 进入录音状态

### 4.4 #/sing/:songId（有参数）交互流程

1. 直接加载歌曲信息
2. 显示「准备演唱: {歌曲名} - {歌手}」
3. 录音按钮可用
4. 录音过程中：实时音高对比显示标准参考线
5. 录音完成后：自动进入 DTW 对比评分

### 4.5 边界条件

| 场景 | 行为 |
|------|------|
| 曲库为空时进入 #/sing | 提示「曲库为空，请先导入标准歌曲」+ 跳转链接 |
| 选择歌曲后取消 | 取消选择，返回选歌列表 |
| 选歌后直接上传已有录音 | 提供「上传已有录音」按钮，跳过录音 |
| 不选歌直接录音 | 使用频率匹配，行为等价于 auto-match |
| 录音中切换歌曲 | 提示「录音进行中，停止后再切换」 |

## 五、对比分析页 (#/compare 改造)

### 5.1 当前状态

Currently ComparePage 只有左右双栏框架，只能从历史记录选取，没有标准音频选择功能。

### 5.2 改造后结构

- **顶部**: 标题「对比分析」+ 模式切换（标准对比 / 历史对比）
- **标准对比模式**:
  - 左栏：标准音频选择（从曲库选 or 上传）
  - 右栏：用户音频选择（从历史记录选 or 上传）
  - 底部评分参数面板（风格选择 + 权重调整）
  - 底部：「开始对比」大按钮
- **历史对比模式**（已有功能）:
  - 左栏：从历史记录选
  - 右栏：从历史记录选

### 5.3 标准音频选择组件

可复用于 #/sing 和 #/compare 的「标准音频选择器」：
- 搜索框
- 歌曲卡片列表（迷你版）
- 「上传新标准音频」按钮
- 已选中状态显示

### 5.4 评分参数面板

- 风格选择器（pop/jazz/classical/folk）
- 五维权重展示（只读显示当前风格预设）
- 「应用并开始分析」按钮

### 5.5 边界条件

| 场景 | 行为 |
|------|------|
| 只选了标准音频 | 提示「请选择用户音频」|
| 只选了用户音频 | 提示「请选择标准音频」|
| 两个都没选 | 按钮禁用 |
| 相同文件用于两边 | 提示「标准音频和用户音频不能相同」|
| 对比结果返回后切换选择 | 清除上次结果，重新分析 |

## 六、复用的标准音频选择器组件

### 6.1 组件接口

`js
class StandardAudioSelector extends BaseComponent {
  constructor(container, options) {
    // options:
    //   onSelect: (song) => void  — 选中回调
    //   mode: 'modal' | 'inline'  — 弹窗模式 / 内联模式
    //   excludeSongId: string     — 排除某歌曲（避免自对比）
  }
}
`

### 6.2 组件状态

| 状态 | UI |
|------|---|
| loading | 骨架屏 |
| empty | 空状态引导 |
| list | 歌曲列表 |
| selected | 已选中高亮 + 详情信息 |
| error | 错误提示 + 重试 |
